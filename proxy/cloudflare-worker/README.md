# Прокси коротких ссылок (Cloudflare Worker)

AdvantShoter превращает ссылку Box `https://app.box.com/s/<id>` в `https://advant.one/<id>`.
Этот воркер отдаёт по такой ссылке **саму картинку** (inline), поэтому она сразу
открывается на телефоне и в превью мессенджеров — без интерфейса Box и без входа.

Как это работает: `GET /<id>` → `https://app.box.com/shared/static/<id>` → ответ с
`Content-Disposition: inline` и кэшированием. Остальные пути передаются на основной
сайт, так что воркер можно повесить на `advant.one/*`.

Условие: у ссылки в Box доступ «Все, у кого есть ссылка» (`open`) — это значение по
умолчанию в настройках AdvantShoter.

## Деплой

```bash
npm i -g wrangler
wrangler login
wrangler deploy      # из этой папки
```

Если используется корпоративный поддомен Box (`company.app.box.com`), задайте его в
`BOX_HOST` в `wrangler.toml`.

> Если у вас уже есть свой прокси — воркер не нужен. Шаблон ссылки настраивается
> в приложении: Настройки → Ссылки (`https://advant.one/{id}`, доступны `{id}`, `{ext}`, `{name}`).
