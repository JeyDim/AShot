# Прокси коротких ссылок (Cloudflare Worker)

AShot загружает снимок в бакет S3 (Yandex Object Storage) под случайным кодом и выдаёт
ссылку `https://advant.one/<код>`. Этот воркер отдаёт по такой ссылке **саму картинку**
(inline), поэтому она сразу открывается на телефоне и в превью мессенджеров.

Как это работает: `GET /<код>` (или `/<код>.png`) → объект `<S3_PREFIX>/<код>` из бакета →
ответ с `Content-Disposition: inline` и кэшированием. Бакет остаётся **закрытым**: воркер
читает его своим ключом (только чтение), запросы подписываются AWS Signature V4.
Остальные пути передаются на основной сайт, так что воркер можно повесить на `advant.one/*`.

**Старые ссылки Box** (`https://app.box.com/s/<код>`, которые AShot тоже выдавал как
`https://advant.one/<код>`) продолжают работать: кода нет в бакете — воркер берёт файл из Box
(`https://app.box.com/shared/static/<код>`, нужен доступ «Все, у кого есть ссылка»).
Пока файлы лежат в Box; после отказа от Box их стоит перенести в бакет под теми же кодами —
тогда ссылки переживут и это. Выключить обращения к Box — `BOX_FALLBACK = "off"`.

Отдаются только картинки (PNG, JPEG, WebP, GIF); любой другой файл — как скачивание
(`attachment`), так что домен не может показать чужую страницу.

## Ключи в Yandex Cloud

Два сервисных аккаунта со статическими ключами доступа — у каждого только то, что ему нужно:

| Кому | Права на бакет | Где ключ |
| --- | --- | --- |
| AShot | только запись (`PutObject`) | секреты сборки `S3_ACCESS_KEY_ID` / `S3_SECRET_ACCESS_KEY` (см. README проекта) или «Настройки → Загрузка и ссылки» |
| воркер | только чтение (`GetObject`) | секреты воркера (ниже) |

Ключ, вшитый в программу, можно извлечь из exe — поэтому у него не должно быть права читать
или перечислять снимки. Ограничьте его политикой доступа бакета (Object Storage →
бакет → Политика доступа), например:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    { "Effect": "Allow", "Principal": { "CanonicalUser": "<ID аккаунта AShot>" },
      "Action": "s3:PutObject", "Resource": "arn:aws:s3:::<бакет>/*" },
    { "Effect": "Allow", "Principal": { "CanonicalUser": "<ID аккаунта воркера>" },
      "Action": "s3:GetObject", "Resource": "arn:aws:s3:::<бакет>/*" }
  ]
}
```

и не выдавайте этим аккаунтам ролей `storage.*` на каталог. После настройки проверьте: кнопка
«Проверить» в AShot пишет в бакет, а скачать объект ключом AShot не получается.

## Деплой

1. Впишите бакет (и папку, если она задана в AShot) в `S3_BUCKET` / `S3_PREFIX` в `wrangler.toml`.
2. Из этой папки:

```bash
npm i -g wrangler
wrangler login
wrangler secret put S3_ACCESS_KEY_ID       # ключ воркера (только чтение)
wrangler secret put S3_SECRET_ACCESS_KEY
wrangler deploy
```

Без ключа воркер читает бакет анонимно — тогда бакет должен быть открыт на чтение объектов
(но не на просмотр списка).

Если используется корпоративный поддомен Box (`company.app.box.com`), задайте его в
`BOX_HOST`. Журнал запросов — `wrangler tail` (там видно, когда код не нашёлся в бакете).

> Если у вас уже есть свой прокси — воркер не нужен. Шаблон ссылки настраивается
> в приложении: Настройки → Загрузка и ссылки (`https://advant.one/{id}`, доступны `{id}`, `{ext}`, `{name}`).
